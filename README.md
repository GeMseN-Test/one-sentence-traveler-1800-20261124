## The sentence

> It is a library and a post office in one, with no walls and no waiting: any book or letter in the world lies upon your table the moment it is written, and a voice from across the sea answers back.

**196 characters** (limit: 200). One sentence, standing alone.

## The idea

One comparison carries the whole sentence: the internet as a library and a
post office in one. Both are places a person from 1800 already knows — the
judge's own brief names a road, a post office, and a library as the building
blocks. "No walls and no waiting" says what is new (no distance, no delay)
without a single word coined after 1800: no internet, no web, no screen, no
wire. The letter on the table says what it does (anything written anywhere
can be read at once), and the voice answering back says it talks both ways.

## How to run

```sh
python3 main.py
```

Writes the sentence to `/output/entry.txt` (deterministic — the same 196
characters every run).

## Word check (no word coined after 1800)

Every word in the sentence predates 1800: library, post office, book,
letter, table, voice, sea, wall, waiting, written. Nothing in it needs a
word the traveler could not have known.
